**The Gilded Vault** — a top-down museum heist. Slip past three patrolling guards and two sweeping security cameras, lift the Sunburst Tiara (plus gems along the way), and get out the green exit before the alarm hits 100%. Shadow alcoves slow the alarm, an EMP freezes the cameras for a price, and a decoy noisemaker lures a guard off his patrol — every tool costs loot, so spend it like it matters.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Move with WASD or arrow keys (or click-and-hold to steer), E for the EMP, Q for the decoy, P to pause.
